ESP32 NodeMCU

IoT Weather Station with ESP32

Project Overview

A robust IoT weather station that reads temperature, humidity, and barometric pressure using a BME280 sensor and publishes live telemetry to an MQTT broker over WiFi.

Components Required

  • 1x ESP32 NodeMCU Board
  • 1x BME280 Temperature/Pressure Sensor
  • 1x 0.96" OLED Display (I2C)
  • Jumper Wires & Breadboard

Wiring / Pinout Guide

BME280 VCC -> 3.3V, GND -> GND, SCL -> GPIO 22, SDA -> GPIO 21. OLED shares the same I2C bus (SCL=22, SDA=21).

Arduino C++ Sketch

#include <WiFi.h>
#include <Wire.h>
#include <Adafruit_Sensor.h>
#include <Adafruit_BME280.h>

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";

Adafruit_BME280 bme; // I2C

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi connected!");
  
  if (!bme.begin(0x76)) {
    Serial.println("Could not find a valid BME280 sensor!");
    while (1);
  }
}

void loop() {
  float temp = bme.readTemperature();
  float humidity = bme.readHumidity();
  float pressure = bme.readPressure() / 100.0F;

  Serial.printf("Temp: %.2f C | Humidity: %.2f %% | Pressure: %.2f hPa\n", temp, humidity, pressure);
  delay(5000);
}
